# mtool マニュアル (v2.0)

## 概要
`mtool.exe` は、Windows 標準のネットワーク制限を回避し、高精度なマルチキャスト診断を行うためのコマンドラインツールです。Npcap ドライバーを活用し、OS の QoS ポリシーをバイパスして正確な DSCP (QoS) タグの付与と、マイクロ秒単位での遅延計測を実現します。

## 主な機能
- **高精度 DSCP 制御**: Windows 10/11 の制限に関わらず、0〜63 の DSCP 値を確実にパケットへ付与。
- **フルインタラクティブ操作**: 実行中にホットキーでグループ、ポート、帯域幅、DSCP 等をリアルタイム変更可能。
- **動的 IGMP 管理**: パラメータ変更時に自動でマルチキャストへの脱退・再加入を実行。
- **手動 IGMP レポート (Forging)**: OS の判断に依存せず、確実に IGMP v3 (SSM) または v2 のレポートを送信。
- **ソース IP 偽装 (Spoofing)**: 送信時に任意のソース IP を名乗ってパケットを送出。SSM 試験に最適。

## セットアップ
1. **Npcap のインストール**: [npcap.com](https://npcap.com/) からダウンロードしてインストールしてください。
   > [!IMPORTANT]
   > インストール時のオプション選択画面で、必ず **「Install Npcap in WinPcap API-compatible mode」** にチェックを入れてください。これがないと `mtool.exe` がライブラリを見つけられず起動できません。
2. **管理者権限**: 本ツールはネットワークの低レイヤーを操作するため、必ず **「管理者として実行」** する必要があります。

## ネットワーク規格と制限
`mtool` は、以下の IETF 標準（RFC）に基づき、有効なパケット生成と診断の整合性を担保します。

- **DSCP (0-63)**: [RFC 2474](https://tools.ietf.org/html/rfc2474) に基づく 6 ビットフィールド。
- **ポート番号 (1-65535)**: [RFC 768 (UDP)](https://tools.ietf.org/html/rfc768) に基づく 16 ビットフィールド。
- **マルチキャストグループ**: [RFC 1112](https://tools.ietf.org/html/rfc1112) に基づく Class D アドレス (`224.0.0.0` 〜 `239.255.255.255`)。
- **TTL (1-255)**: 8 ビットの生存期間。ルーターを越える場合は 2 以上の設定を推奨。
- **パケットサイズ (最大 1472 byte)**: 標準的な Ethernet MTU (1500 byte) において、IP (20) と UDP (8) の各ヘッダーを除いた、フラグメンテーションが発生しない最大ペイロードサイズ。

## 使用方法

### 1. ウィザード形式 (推奨)
引数なしで実行すると、対話形式でセットアップが始まります。
```cmd
mtool.exe
```

### 2. コマンドライン引数
```text
-m, -Mode      : モード (send / recv)
-i, -Interface : 使用する NIC の IP アドレス
-g, -Group     : マルチキャストグループ (Default: 239.1.1.1)
-p, -Port      : UDP ポート番号 (Default: 5001)
-s, -Source    : ソース IP (IGMP v3 用)
-v, -IGMP      : IGMP バージョン (2 / 3)
-q, -QoS       : DSCP 値 (0-63)
-b, -BW        : 目標帯域幅 (Mbps)
-t, -TTL       : TTL 値
-sz, -Size     : パケットサイズ (Bytes)
-w, -WebPort   : WebUI ポート
```

## 実行中の操作 (ホットキー)
動作中に以下のキーを押すことで、リアルタイムに設定を変更できます。
- `G`: グループアドレスの変更 (Re-Join)
- `S`: ソース IP の変更 (Re-Join / Spoofing)
- `O`: ポート番号の変更
- `V`: IGMP バージョンの切り替え (2 ⇔ 3)
- `M`: IGMP v3 モードの切り替え (Include ⇔ Exclude)
- `D`: DSCP 値の変更
- `B`: 目標帯域幅 (Mbps) の変更
- `P`: パケットサイズの変更
- `T`: TTL の変更
- `R`: 初期設定への復元 (Restore)
- `C`: 統計情報のクリア
- `Q`: プログラムの終了

## ログ記録・レポート機能
`mtool` は、ネットワーク検証のエビデンスを自動生成するログ記録機能を備えています。

- **操作**: 
  - WebUI 上の 「Start Logging」ボタンで記録を開始します。記録中は「LOGGING」インジケーターが表示されます。
  - 「Stop & Download CSV」をクリックすると記録が終了し、自動的に CSV ファイルがブラウザ経由でダウンロードされます。
- **記録内容 (CSV)**:
  - タイムスタンプ、イベント（JOIN/LEAVE/QUERY/設定変更）、スループット、遅延、ジッター、パケットロス、詳細パラメータが 1 秒間隔およびイベント発生時に記録されます。

## 統計の見方
- **TX-pps / Mbps**: 送信パケット数とスループット。
- **RX-pps / Mbps**: 受信パケット数とスループット。
- **Loss%**: 連番によるパケットロス率。
- **Lat-Avg / Jitter**: マイクロ秒単位の平均遅延と揺らぎ。
- **DSCP**: 受信パケットに含まれる実際の DSCP 値（`設定値(実測値)`）。赤字の場合は不一致。

## トラブルシューティング
- **"Malformed Packet"**: Wireshark で IGMP が壊れていると言われる場合は、最新版の `mtool_npcap.exe` を使用してください。
- **受信できない**: Windows Firewall またはウイルス対策ソフトを確認してください。SSM の場合は、送信元 IP が `Source IP` 設定と一致しているか確認してください。
- **Npcap Error**: Npcap が正しくインストールされているか、他のアプリが NIC を独占していないか確認してください。
